Privacy Policy

Last updated: 17 November 2026

Youtube Lucky is a private desktop tool used only by its own team to upload videos to the team's own YouTube channels. This policy explains how it handles Google user data.

Data the tool accesses

  • An OAuth access token and refresh token for each connected YouTube channel.
  • The connected channel's ID and name, read with the YouTube Data API.
  • The video, thumbnail, captions and text the operator chooses to upload.

How the data is used

The data is used only to upload videos, thumbnails and captions that the operator has reviewed and confirmed, and to show which channel an upload will go to. It is not used for advertising, profiling, analytics or any other purpose.

Storage

Tokens are stored only on the team's own Windows computer, encrypted with Windows Data Protection (DPAPI) for the signed-in Windows user. There is no server: the tool talks directly to Google APIs. A local log on the same computer records the date, channel and video ID of each upload.

Sharing

Google user data is not sold, shared with or transferred to any third party. It is sent only to Google, as needed to call the YouTube Data API.

Retention and deletion

Tokens are kept until the operator disconnects the channel in the tool, which deletes them from the computer. Access can also be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Youtube Lucky's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Uploads are subject to the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions about this policy can be sent to the support email shown on the Google consent screen of this app.
